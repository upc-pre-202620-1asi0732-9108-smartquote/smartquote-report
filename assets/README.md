# Organización de assets

Esta carpeta reserva las ubicaciones de los archivos que se insertarán posteriormente en el informe. Mantener nombres descriptivos, en minúsculas y con guiones (`kebab-case`).

| Ruta | Contenido previsto |
|---|---|
| `cover/` | Logo institucional para la carátula. |
| `profiles/` | Fotografías de integrantes. |
| `research/competitors/` | Evidencias del análisis competitivo. |
| `research/interviews/` | Capturas de las entrevistas. |
| `research/needfinding/` | User Personas, User Journeys, Empathy Maps y Scenario Maps. |
| `requirements/` | Impact Map, Product Backlog y otros artefactos de requisitos. |
| `design/style-guides/` | Branding, tipografías y guías visuales. |
| `design/landing-page/` | Wireframes y mock-ups de la Landing Page. |
| `design/mobile/` | Wireframes, wireflows, mock-ups y user flows móviles. |
| `design/web/` | Wireframes, wireflows, mock-ups y user flows web. |
| `architecture/` | Diagramas de arquitectura, clases y base de datos. |
| `implementation/` | Evidencias de sprints, pruebas, despliegues y colaboración. |
| `videos/` | Capturas representativas de los videos enlazados en el informe. |
| `annexes/` | Assets que correspondan a anexos del AV1. |

No almacenar videos ni archivos fuente pesados en esta carpeta salvo que el repositorio lo requiera expresamente; para el informe usar capturas y enlaces según el enunciado.
